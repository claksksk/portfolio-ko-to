# BSIT Professional Portfolio | Clarize C. Villanueva

## Overview
This repository contains the professional portfolio website for my **BSIT 4th Year Final Defense**. The web application showcases my academic journey, technical skills, major projects, problem-solving case files, and employability documentation.

## Features & Sections
- **Interactive Home & Profile:** Built with modern glassmorphism design, responsive layouts, and personal background credentials.
- **Technical Skills Matrix:** Highlights advanced proficiencies in Python, JavaScript, SQL, HTML/CSS, Bootstrap, and database management.
- **Major Projects Portfolio:** 
  - *Project 1:* AI-Assisted Student Academic Management System (Full-stack CRUD web app with session auth and AI assistant).
  - *Project 2:* Student Performance Analysis & Early-Warning Dashboard (SQL, Excel visualization, and Python analytics).
  - *Specialization Project:* AI-Assisted IT Help Desk & Service Ticket Management.
- **Problem-Solving & Cybersecurity:** Documented IT troubleshooting cases and cybersecurity mitigation case studies (e.g., SQL Injection defense).
- **Employability & Professional Links:** Direct links to GitHub repository, LinkedIn profile, career development plan, and official resume.

## Technologies Used
- HTML5, CSS3, JavaScript (ES6)
- Bootstrap 5 Framework
- FontAwesome Icons & Google Fonts
- AOS (Animate On Scroll) Library
- HTML5 Canvas (Live Particle Animations)
